# v2.9.3 修复说明：补录 SM8650 历史指纹

作者：ZenJooo · 2026-10 · versionCode 393 · 配置代际 380

## 问题

v2.9.1 为升级识别补录历史出厂指纹时，SM8650 错放了**均衡重调批次**的
`b282aaed50e40878`，而 v2.8.0 / v2.9.0 实际出货的 SM8650 模板是**真机
OPP 重调批次**的 `2d070c1ed3e39a2a`。

后果：从 v2.8.0 / v2.9.0 升级的 SM8650 用户，未编辑过的默认配置指纹
不在列表中 → 被当作自定义配置**原位保留** → 升级后拿不到后续模板更新
（不影响安装成败，只影响升级时的配置自动更新）。

## 修复

两个批次的指纹并存于 `STOCK_FINGERPRINTS`；旧批次（governor=auto）与新
批次（显式 walt/schedutil）均可识别，识别为出厂后自动替换为最新模板。

- 安装第三幕的硬件检测与该问题无关；如管理器安装报错，请把管理器界面
  的具体报错文字反馈给作者（或安装后从 WebUI「运行诊断」读取日志）。
- 其余改动无；版本 2.9.3 / 393，配置代际 380 不变。
