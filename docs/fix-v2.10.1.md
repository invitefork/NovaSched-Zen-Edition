# v2.10.1 修复说明：待机功耗与 FAS 防炸功耗守门

作者：ZenJooo · 2026-10 · versionCode 401 · 配置代际 390

## 1. 待机功耗（全处理器）

- **桌面/系统界面不再保持任何加压**：前台为桌面（MIUI 桌面、原生
  Launcher、各厂商桌面）或 SystemUI 时，NovaFAS 置为不可调度——加压、
  uclamp 底频全部释放，待机功耗完全交给内核 idle。覆盖 MIUI/原生/
  Google/OPPO/vivo/三星/华为桌面。
- 出厂模板 FAS 上限下调：省电档 uclamp 上限 35→28、抬频 30→25；
  均衡档 55→45。性能/极速不变。

## 2. FAS 防炸功耗守门（稳定性）

- **应用切换清零加压**：此前切换应用时控制器 boost 原样带过去（旧游戏
  的加压遗留到新应用）。现在前台包一变即归零并强制重写目标。
- **停更泄压守门**：加压 > 0 而帧/负载信号停更超过 8 秒（应用停止渲染、
  采样失效），按 2 倍速率受控泄压到 0——加压值绝不悬挂在高位。信号
  恢复后自动停止泄压。

## 3. 处理器适配确认（本期采集）

- OPPO PHN110（kalama / SM8550，policy0/3/7，walt + uag）：命中现有
  SM8550 档案，百分比模板自动吸附其 OPP（小核最高 2.016G）。
- 小米 pandora（25098PN5AC / SM8850，policy0(0-5)/6(6-7)，小核最高
  3.6288G、大核 4.608M）：命中现有 SM8850 档案。
- 两台均无需新条目；`uag` 调速器存在但模板显式写 walt（可用）。

## 版本

- 版本 2.10.1 / 401；配置代际 390 不变（FAS 上限变化通过出厂指纹批
  次更新，未编辑配置升级自动获得）。
