# v2.9.5：Scene 自动接管和 WebUI 连接

作者：ZenJooo · versionCode：395 · 配置代际：380

旧版把已有 Scene LP 回调识别为外部调度器，跳过注册，也不再重试。修复为检测到 Scene 后备份 `powercfg.json`、`powercfg.sh`、`powercfg-base.sh` 的内容和权限，再替换为 NovaSched。安装和开机复查，运行中被重写时重新接管，保留首次备份供卸载恢复。

安装暂存路径换成重启后的正式模块路径，停用模块后回调不执行。WebUI 显示具体连接错误，宿主桥稍晚就绪时自动重试，兼容原生异步空返回及不同 exec 参数形式。离线状态卡提供诊断与启动入口，服务缺失时每次开机最多补启动一次。

本版仍受旧用户识别门槛影响，该启动兼容问题由 v2.9.6 继续修复。
