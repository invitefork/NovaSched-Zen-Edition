# v2.9.2 修复说明：全新原创壁纸

作者：ZenJooo · 2026-10 · versionCode 392 · 配置代际 380

## 背景

旧内置浅色壁纸是动漫人物插画：人物面部正好落在档位卡片区域，与操作
争抢视觉重心，且存在第三方版权风险；深色壁纸为高饱和蓝色照片，长时间
观看偏刺激。

## 新壁纸（程序化生成，完全原创）

用分层径向色场在小尺寸画布绘制后双三次放大（天然柔化）+ 细噪点合成：

- **浅色**（基色 #e9eef5）：上缘雾蓝 → 右侧长春花紫 → 左下薄荷 → 底部
  暖白；右上一点淡金高光。无大面积亮白，明暗过渡平缓。
- **深色**（基色 #0d1015）：近黑底 + 上缘钢蓝、右侧暗靛、左中青、底部
  暗紫的色调场 + 右上柔光源；保留明暗层次供玻璃折射，不刺眼。
- 细噪点（浅 α9 / 深 α15）确保液态玻璃边缘折射、高光与透色有纹理可
  依；标题、列表与底部导航所在的中段保持平静。
- 竖屏 1080×2340 构图：视觉重心在上缘与底部；横屏裁切取中段，过渡平
  滑无截断；深浅两版风格一致，切换协调。
- 本地打包 JPEG（浅 156KB / 深 218KB），断网正常显示；加载底色与壁纸
  基色同步（body 背景与 theme-color：#e9eef5 / #0d1015），不再闪白。
