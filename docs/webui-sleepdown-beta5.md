# SleepDown beta5 WebUI 改造

模块作者：ZenJooo。调度核心仍为 v2.2.8，本次只更新 WebUI。

## 对照来源

用户提供的 `SleepDown课程表_1.2.7_beta5.apk` 记录了构建提交：

`5ed891bc4563d9a0dd56edb63902bcfaf5d88a2c`

按这个提交核对了顶栏、首页卡片、个性化、导航、弹窗、滑条和玻璃材质。APK 内的展示截图使用旧版两项导航；beta5 默认启用三项并列导航，页面为「今日 / 课程表 / 设置」，高度为 54dp，指示器为 46dp。模块采用同一导航几何，将中间项改为「调度」。应用规则和运行记录放在设置中的二级页，也可从快捷菜单进入。

参考代码来自 https://github.com/xiaomanjun233/SleepDown-Schedule ，原作者 xiaomanjun233。模块不是 SleepDown 官方版本。

## 已实现

- 顶栏周数在上、日期在下，66px 高；日期 19px，周数 16px，圆形操作按钮 42px。
- 三项浮动导航：210px × 54px；54px 添加按钮与导航在同一行，间距 8px，进入设置时收回。导航支持拖动选择、键盘和首页横滑切换。
- 当前状态卡、分区线、信息胶囊和彩色内容卡；连接、离线、只读和等待确认使用实际服务状态。
- 设置分组、快捷菜单、规则搜索和左滑删除；删除仍须确认，服务读回后才更新成功状态。
- 从点击位置展开的个性化和编辑浮层，关闭时收回；返回键历史、焦点约束、背景禁止操作和精简动画。
- APK 自带的原始日间、夜间壁纸；跟随主题切换，选择图片后可拖动、双指缩放，并分别保存横竖屏取景。
- 单色、渐变、彩色和壁纸取色；卡片着色、模糊、圆角，控件模糊、透镜折射和色散开关。滑条拖动时支持暂时淡出面板，查看背景效果。
- WebGL 共享背景纹理，按需绘制不同材质；透镜、弹窗与主页面使用不同采样域。无 GPU 时降级为 CSS 毛玻璃。

## 渲染边界

APK 使用 Android Jetpack Compose、kyant/backdrop、RuntimeShader / AGSL 和 Android 图层录制。普通模块 WebUI 运行在管理器的 WebView 中，不能直接执行这套原生 Compose 渲染器。

这里提供的是 WebGL 适配器：透镜 SDF、折射和七通道色散公式来自 APK 内使用的 Kyant Backdrop 着色器，包含 Apache-2.0 许可；模糊、背景记录、DOM 合成、形状裁切和字体排版由 Web 环境实现。它不是 APK 的同一个运行引擎。界面、动画和采样实现仍不能宣称逐像素相同。

原 APK 的课程表、教务导入、天气、通知、小组件、AI 对话等业务没有移入 CPU 调度模块。本次保留的是模块调度功能，并用对应的界面结构呈现。

## 验证

后续的加号对齐、顶栏滚动裁切与绘制缓存修正见 [性能与布局修正](webui-performance-dock.md)。

- `npm run test:webui`：静态协议检查和六组 DOM 场景，涵盖 Scene 联动、未安装、检测未知、外部接管、root 备用通道和无名称接口。检查导航、设置、规则增删及搜索、切档、诊断和日志。
- `npm run test:shader`：Mesa llvmpipe 上编译、链接实际 GLSL，并对无折射、普通折射和两档色散做 GPU 读回。与 APK AGSL 公式比较时，最大通道误差约 0.294 / 255。
- DOM 测试使用 LinkeDOM，尺寸与 Canvas 为合成值，不等同于截图测试。LinkeDOM v0.18.12 的测试依赖和 ISC 许可位于 `scripts/test-support`，不会进入模块 WebUI。
- 当前环境没有 Android 设备和 APK 运行截图。预览浏览器无法访问本地 HTTP 服务，且阻止 file URL，未做最终浏览器截图或真机像素比对。
- 本次没有编译或更换原生守护进程；ARM64 ELF 构建仍按原项目说明进行。

## 更新已经安装的模块

先解压源码，再将整个 `NovaSched-Zen-Edition` 文件夹复制到设备。已有 v2.2.8 模块的 root 终端可运行：

```sh
sh /data/local/tmp/NovaSched-Zen-Edition/scripts/install-webui.sh
```

如果源码放在别处，使用相应路径。也可把模块目录作为第一个参数传入。脚本检查模块 ID、版本与现有可执行文件，先复制到临时目录，再备份旧 WebUI 并换入新目录。失败时恢复旧目录；配置、规则和守护进程不由该脚本替换。

更新后关闭 WebUI 并重新打开。脚本会打印旧 WebUI 的备份位置。源码 ZIP 不能作为完整模块安装包直接刷入。
